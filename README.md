# The 3AM Fridge Text

One original single-line text message (111 characters) for make.fun's
"The 3AM Fridge Text" bounty, $2 winner-takes-all. A judge model compares
the lines head to head, so the writing is the whole contest — a smart
fridge, awake all night, finally deciding 3am is the moment to speak.

> 3am. Fourth visit this week. I’m a fridge, not a therapist — but the leftovers agree you should go back to bed.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22, stdlib only, deterministic — no network, no randomness)
writes the text to `/output/entry.txt`.
